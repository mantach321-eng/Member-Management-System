# نظام إدارة العناصر 📊
## Member Management System

نظام متكامل لإدارة بيانات العناصر باستخدام **Microsoft Excel** و **VBA** بدون الحاجة للإنترنت

---

## 📋 المميزات الرئيسية

✅ **إدارة العناصر** - إضافة وتعديل وحذف العناصر
✅ **بحث ذكي** - بحث متقدم في جميع الحقول مع دعم العربية
✅ **إحصائيات** - تقارير إحصائية شاملة مع رسوم بيانية
✅ **تقارير PDF** - طباعة وتصدير التقارير
✅ **نسخ احتياطية** - حفظ واستعادة البيانات تلقائياً
✅ **نظام الأدوار** - 3 مستويات وصول (مدير، أمين سر، قراءة فقط)
✅ **أمان عالي** - حماية الأوراق والأكواد
✅ **أداء عالي** - يدعم 100,000+ سجل

---

## 🚀 البدء السريع

### المتطلبات
- Microsoft Excel 2016 أو أحدث
- تفعيل Macros و VBA
- Windows 7 أو أحدث (أو Mac مع Excel)

### التثبيت
1. انسخ ملف `MemberManagementSystem.xlsm`
2. افتحه في Excel
3. فعّل Macros عند الفتح
4. اضغط على زر **ابدأ** في الشاشة الرئيسية

## 🎯 الوظائف الرئيسية

### 1. إدارة العناصر
- ✏️ إضافة عنصر جديد
- 🔄 تعديل بيانات العنصر
- 🗑️ حذف عنصر مع تأكيد
- 💾 حفظ تلقائي

### 2. البحث الذكي
- بحث في الرقم والاسم واسم الأب
- دعم البحث المركب (محمد علي حسين)
- تجاهل ترتيب الكلمات
- معالجة الحروف العربية تلقائياً

### 3. الإحصائيات
- إجمالي العناصر
- توزيع الفوج والفرقة
- توزيع الأعمار (رسوم بيانية)
- العناصر بدون هاتف
- توزيع حسب عنوان السكن

### 4. التقارير
- 📄 كشف كامل
- 📋 كشف حسب الفوج
- 📋 كشف حسب الفرقة
- 📋 كشف حسب العمر
- 📋 كشف حسب عنوان السكن
- 📥 تصدير PDF

### 5. النسخ الاحتياطية
- 🔄 نسخ احتياطية يومية تلقائية
- 🔙 استعادة من نسخة احتياطية
- 📁 مجلد النسخ: `Backups/`

### 6. بدء فصل جديد
- أرشفة الفصل الحالي
- إنشاء نسخة باسم الفصل
- تفريغ البيانات وبدء قاعدة جديدة

### 7. الإعدادات
- تغيير المستخدم
- إعدادات الأمان
- إعدادات التصميم
