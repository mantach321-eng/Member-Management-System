# دليل التثبيت والبدء السريع

## 📋 المتطلبات الأساسية

✅ **Microsoft Excel 2016** أو أحدث
✅ **نظام تشغيل Windows 7** أو أحدث (أو Mac مع Excel)
✅ **مساحة تخزين**: 50 ميجا بايت على الأقل

---

## 🔧 خطوات التثبيت

### الخطوة 1: تحميل البرنامج
1. انسخ ملف `MemberManagementSystem.xlsm`
2. ضعه في مجلد على جهازك
3. لا تقلق بشأن المتطلبات الإضافية - كل شيء مضمن!

### الخطوة 2: فتح الملف
1. افتح Excel
2. اضغط على **File → Open** أو **Ctrl + O**
3. ابحث عن `MemberManagementSystem.xlsm`
4. انقر عليه واضغط **Open**

### الخطوة 3: تفعيل Macros
⚠️ **مهم جداً**

عند فتح الملف لأول مرة، قد تظهر رسالة:
```
"تحذير الأمان: تم تعطيل ماكروس في هذا المصنف"
```

**اختر: Enable Macros** أو **تفعيل الماكروس**

إذا لم تظهر الرسالة:
- اذهب إلى **File → Options → Trust Center**
- اختر **Trust Center Settings**
- اضغط على **Macro Settings**
- اختر **Enable all Macros** أو **تفعيل جميع الماكروس**

### الخطوة 4: بدء البرنامج
1. بعد تفعيل الماكروس، ستظهر نافذة تسجيل الدخول
2. استخدم بيانات الدخول التالية:

| المستخدم | كلمة المرور | الدور |
|---------|-----------|-------|
| admin | admin123 | مدير |
| secretary | sec123 | أمين سر |
| user | user123 | قراءة فقط |

3. اختر المستخدم واكتب كلمة المرور
4. اضغط **دخول** أو **Login**

## 🎯 أول استخدام

### إضافة بيانات
1. من الشاشة الرئيسية، اختر **إدارة العناصر**
2. اضغط على **إضافة عنصر جديد**
3. أدخل البيانات المطلوبة
4. اضغط **حفظ**

### البحث عن عنصر
1. اختر **البحث**
2. اكتب الاسم أو الرقم
3. اضغط **ابحث**
4. ستظهر النتائج مباشرة

### عرض الإحصائيات
1. اختر **الإحصائيات**
2. ستشاهد:
   - إجمالي العناصر
   - توزيع الأفواج
   - توزيع الفرق
   - توزيع الأعمار (رسم بياني)

## ⚠️ نصائح مهمة

### النسخ الاحتياطية
- ✅ البرنامج ينشئ نسخة احتياطية **تلقائياً يومياً**
- ✅ لا تحتاج لعمل شيء، كل شيء تلقائي
- ✅ في حالة الطوارئ، استخدم **استعادة نسخة احتياطية**

### الأداء
- 🚀 البرنامج سريع جداً حتى مع 100,000 سجل
- 💾 احفظ العمل بانتظام (Ctrl + S)
- 🔄 أغلق البرنامج بشكل صحيح (لا تقطع الكهرباء فجأة)

### الأمان
- 🔒 تسجيل دخول محمي بكلمة مرور
- 🛡️ الأوراق محمية من التعديل غير المصرح
- ⚠️ تأكيد قبل حذف أي بيانات

## 🆘 استكشاف الأخطاء

### المشكلة: لا تظهر الشاشة الرئيسية
**الحل:**
1. أغلق الملف تماماً
2. افتحه مرة أخرى
3. تأكد من تفعيل الماكروس

### المشكلة: خطأ عند البحث
**الحل:**
1. تأكد من كتابة البيانات بشكل صحيح
2. جرب البحث عن كلمة واحدة فقط
3. تحقق من عدم وجود مسافات إضافية

### المشكلة: النسخة الاحتياطية لا تعمل
**الحل:**
1. تأكد من وجود مجلد `Backups` بجانب الملف
2. تحقق من صلاحيات المجلد
3. احفظ الملف في مجلد بسيط (مثل Desktop)
